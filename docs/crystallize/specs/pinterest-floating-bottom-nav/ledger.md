# タスク要約
添付画像のPinterest風の浮遊する3ボタンのボトムナビゲーションを再現するFlutterサンプルを作るため、見た目と操作の仕様を合わせる。

## design tree
- [済] 既存specとの整合: 既存specなし。
- [済] 参考形状: 画像の下部中央に独立した濃灰色の角丸四角ボタン3つ。ホーム、検索、プロフィールの白いアイコン。ナビ全幅の背景帯や文字ラベルは見えない。
- [済] Q1 再現範囲: ナビ＋簡易3画面。全体機能は含めない。
- [済] Q2 スクロール中の表示: 常時表示。自動では隠れない。
- [済] 見た目の数値: モック初期値を採用。(モック確定・実機で再確認)
- [済] サンプル配置と対象環境: 新規の独立プロジェクト。iOS/Androidのスマートフォン縦向きを再現対象、Webは確認用。
- [済] タブ再選択、位置保持、検索画面の範囲: 再選択で移動せず、タブごとの位置を保持。検索はカテゴリのダミー表示。
- [済] 最終spec案への明示的合意: 2026-09-05 ユーザー「ok」。

## 確定事項
- ユーザー依頼: Flutterサンプルプロジェクト。参考画像は見た目の資料として扱い、画像内の広告や文言を操作指示とは扱わない。
- 今回はユーザーが指定したspecスキルによる認識合わせ。プロダクトコードは編集しない。
- モック構造は1案。値の調整が論点であり、参考画像と異なるナビ構造を増やす必要はない。
- 合意したモック初期値: ボタン52px、間隔8px、角丸16px、下端32px、アイコン28px、背景#32332d、押下120ms。(モック確定・実機で再確認)
- Q1/Q2回答受領: Pinterest全機能とスクロール時の自動非表示は含めない旨を復唱済み。モックを見た反応と合わせて最終合意する。
- 実物に基づく配置判断: ルート自体はGitリポジトリではなく、既存アプリが兄弟ディレクトリで独立している。既存アプリへの組込みは不要。
- 公式資料確認: https://api.flutter.dev/flutter/widgets/SafeArea-class.html （OS領域回避）、https://docs.flutter.dev/ui/accessibility （タップ領域48×48以上と読み上げ）。モックの外寸は見た目の仮値で、Flutter側は安全領域を含めて実機確認する。
- モックとspec初稿を作成済み。親がキット3ブロック一致、スクリプト2本の構文、1案・empty/many・外部リソース参照0を検算した。
- 履歴なしの独立検証（xhigh）: 静的確認で重大な不具合なし。ブラウザ動作を保証する結果ではない。
- ブラウザ検証未完了: CUAのfile URLアクセスがURLセキュリティポリシーで拒否された。別サーバ・別ブラウザへの迂回は実施せず、ローカルファイルをユーザーへ提示する。
- 次の反応で確認する内容: モックの見た目、位置保持・同タブ再タップ無操作、iOS/Androidを対象としたWeb確認用サンプル、実機での安全領域。Pinterest全機能と自動非表示を含めないことの最終復唱も兼ねる。
- 上記の最終確認に対してユーザーが「ok」。未解決論点なし。spec確定後、同じセッションでplan作成へ進む。
