# Pinterest風の浮遊ボトムナビゲーションをFlutterサンプルで再現する

> 2026-09-05 合意済み。モックと仕様案へのユーザーの「ok」をもって確定。Flutter実機での見た目・操作感の確認は実装後に行う。

## 課題
添付画像にある、独立した3つの角丸ボタンがコンテンツ上に浮かぶナビゲーションをFlutterで試したい。Pinterest全体の機能を作る必要はなく、ナビの形状、配置、タップ時の反応、画面切り替えを確認できればよい。

## 解決
単独で起動できるFlutterサンプルを用意し、黒背景のダミーコンテンツにホーム・検索・プロフィールのナビを重ねる。スクロールしてもナビを表示し続け、3画面を切り替えて試せるようにする。

## 要件
- ナビは下部中央の独立した3つの濃灰色の角丸四角ボタンで構成する。全幅の背景帯や可視の文字ラベルは付けない。(モック確定・実機で再確認)
- 左からホーム、検索、プロフィール。初期選択はホーム。選択中は白の塗りアイコン、非選択は白の線画で区別する。色だけで選択を伝えない。(モック確定・実機で再確認)
- 別のボタンをタップすると対応する簡易画面に切り替わる。画面遷移履歴は積み上げず、常に選択は1つだけとする。
- スクロール中もナビは固定して常時表示する。下方向のスクロールでも自動では隠れない。
- タブごとのスクロール位置を実行中に保持する。選択中のタブの再タップでは先頭に戻らない。再起動後の位置は復元しない。
- 押したボタンは短く縮小し、離す・キャンセルする際に戻る。指を外して離した場合は画面を切り替えない。
- ホームは高さの異なる2列のダミーカード、検索は見本のカテゴリ、プロフィールはダミー情報を表示する。実際の検索・ログイン・画像保存には接続しない。
- 背景の内容はナビの背後までスクロールする。末尾には余白を設け、最後の内容がナビの下に隠れたままにならない。
- 見た目の基準値はボタン52、間隔8、角丸16、アイコン28（寸法は論理ピクセル）、背景色#32332d、押下時間120ms。下端余白は32を基準にOSの安全領域を避け、実機で位置を再確認する。(モック確定・実機で再確認)

## 非機能要件
- iOS/Androidのスマートフォン縦向きを再現対象とし、Webでも確認用に起動できる独立サンプルとする。広い画面でもナビは下部中央に配置する。
- 実行時の外部通信を必要とせず、ダミー内容を表示できる。
- ナビのタップ領域を48×48論理ピクセル以上とし、読み上げで各ボタンの名前と選択状態を判別できる。
- OSの操作領域とナビが重ならず、幅320〜430論理ピクセルで3ボタンが収まる。
- 起動方法と再現範囲を日本語の説明にまとめる。

## スコープ外
- Pinterest全体の複製、広告、画像の完全再現、投稿、メッセージ、ログイン、検索バックエンド、保存機能。
- スクロール時のナビ自動非表示、タブ再タップで先頭へ戻る機能、アプリ再起動後の状態保存。
- ライトテーマ、タブレット専用の画面設計、公開・ストア配布。

## 用語
- **浮遊ナビ**: 背景帯で画面を区切らず、コンテンツに重ねて表示する3つの独立ボタン。
- **簡易3画面**: ナビによる切り替えを確認するための、外部サービスに接続しないホーム・検索・プロフィール。
